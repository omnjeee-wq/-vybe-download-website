VYBE DOWNLOAD WEBSITE
=====================

Included:
- Responsive static landing page (HTML/CSS/JS)
- Your VYBE logo and 4 app screenshots
- Telegram community link: https://t.me/VyomaOfficial
- Download section configured for a 30 MB APK

IMPORTANT — ADD YOUR APK:
1. Copy your APK into the `downloads` folder.
2. Rename the APK exactly to: VYBE.apk
3. The final path must be: downloads/VYBE.apk

DEPLOY TO GITHUB + VERCEL:
1. Extract this ZIP.
2. Add downloads/VYBE.apk.
3. Upload the extracted folder contents to a GitHub repository (not the ZIP itself).
4. In Vercel, import that GitHub repository.
5. Framework Preset: Other.
6. Build Command: leave empty.
7. Output Directory: . (root).
8. Deploy.

No backend or database is required. This is a static website.
The APK is not included in this ZIP because it has not been uploaded in this chat.
